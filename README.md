# MVP_project
Анализ зарплат и ВВП в России
Это веб-приложение на базе Streamlit, предназначенное для анализа номинальных и реальных зарплат в разных отраслях экономики России в сопоставлении с инфляцией и ВВП.
Функционал приложения
Шаг 1. Загрузка данных
Пользователь загружает три Excel-файла:
1.1 Таблица с номинальными зарплатами (отрасли — строки, годы — столбцы по возрастанию);
1.2 Таблица с ВВП (одна строка — годы в столбцах);
1.3 Таблица с инфляцией (одна строка — годы в столбцах).
Для удобства доступны примеры шаблонов ввода.

Шаг 2. Отбор отраслей
Предоставляется мультивыбор отраслей из таблицы зарплат. По умолчанию выбраны первые две доступные.

Шаг 3. Визуализация данных
График 1. Номинальные значения
3.1 Отображаются:
3.1.1 Номинальные зарплаты по выбранным отраслям;
3.2.2 Номинальный ВВП.
График 2. Реальные значения
3.2 Проводится дисконтирование по инфляции. Отображаются:
3.2.1 Реальные зарплаты;
3.2.2 Реальный ВВП.
График 3. Темпы роста
3.3 Вычисляется рост в процентах по годам:
3.3.1 Номинальный рост зарплат по отраслям;
3.3.2 Реальный рост зарплат;
3.3.3 Рост ВВП.

Шаг 4. Расчетные показатели и выводы
4.1 CAGR (среднегодовой темп роста)
4.2 Для каждой отрасли выводится значение CAGR по номинальным и реальным зарплатам.
4.3 Годы с максимальным и минимальным ростом
4.4 Показываются годы:
4.4.1 с наибольшим и наименьшим номинальным ростом;
4.4.2 с наибольшим и наименьшим реальным ростом.
4.5 Корреляция с ВВП: вычисляется коэффициент корреляции между ростом зарплат и ВВП по каждой отрасли с интерпретацией чувствительности.
4.6 Когда рост зарплат обгонял инфляцию: для каждой отрасли отображаются годы, в которые реальный рост зарплат превышал уровень инфляции.
